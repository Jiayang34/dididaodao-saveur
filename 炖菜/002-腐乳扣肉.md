# 002 腐乳扣肉

## 食材

| 食材          |        用量 |
|-------------|----------:|
| 猪五花（最好为剔骨肉） |    1.5 kg |
| 生抽          |       6 勺 |
| 老抽          |        适量 |
| 王致和腐乳       |  6块+适量腐乳汁 |
| 葱、姜         |        适量 |
| 大料          |       5 颗 |
| 水           |        适量 |

## 做法

### 预处理

1. 五花肉凉水下锅，加入料酒、葱姜、花椒和大料3颗（必须加）焯水。第一次煮沸后撇净血沫，保持中小火，使水呈半沸状态。分三次加入凉水，持续撇净浮油和剩余血沫。
2. 不用捞出，转小火慢炖一小时（或高压锅上汽后300w 25min），直至筷子可以轻松穿透
3. 捞出后趁热在猪皮上抹上老抽上色（不必须，但是必须趁热），然后晾凉备用
4. 凉透后炸猪皮（不必须，只为成品呈现虎皮状），油热后猪皮朝下炸五分钟（或空气炸锅，猪皮朝上200度 25分钟），直至猪皮起大泡
5. 凉透后，泡入肉汤继续放凉。

### 烹饪步骤

1. 切葱姜丝备用；取两颗大料焙黑后尽量碾成细末（或直接使用十三香/五香粉）；腐乳加少量水，尽可能碾碎成细密的腐乳酱。
2. 捞出炸完皮的五花肉，确保完全凉透，按个人偏好切薄片，猪皮朝下摆在碟子中
3. 6勺生抽均匀地浇在肉上，将腐乳酱抹在肉上（包括肉片之间的缝隙也应尽可能抹上腐乳酱）
4. 撒上大料粉/颗粒, 最后最上层平铺葱姜丝
5. 水开后，普通锅蒸2-3个小时（越久肥肉化开越充分，以个人口味为准，不低于一个半小时），或高压锅上汽后500w 40分钟
6. 蒸完取出，将碟子内肉汤和表层油滤出，另准备合适大小的碗，将肉扣在碗中（现在皮朝上），再倒回滤出的汤汁

## 补充说明

- 猪五花尽量选择较厚的剔骨肉（仅剔除肋骨但保留排骨肉的五花肉），根据新鲜程度决定焯水前是否要泡水
- 焯水和水煮时必须放大料，并且水煮时间不宜过长，筷子可以轻松穿透即可关火
- 炸猪皮、切片前务必保证肉已经凉透，防止翻动、切片时破坏肉块完整性
- 炸猪皮前还应保证表面干燥防止溅油，最后扣入碗中也要保证汤汁已滤净，防止烫伤
- 腐乳酱要尽可能涂抹到肉片之间，所以不易过稀。但是为防止成品汤汁太多，也不应加入太多水，保持酱汁挂在肉上不流动为宜（多腐乳汁少额外加水）
