# 001 排骨炖豆角焖卷子

## 食材

| 食材 |            用量 |
| --- |--------------:|
| 猪排骨 |        1.5 kg |
| 五花肉（肥瘦比 1∶1） |         250 g |
| 面粉 |     按人数和食量取适量 |
| 豆角 |            适量 |
| 土豆 |            适量 |
| 黄豆酱 |           3 勺 |
| 生抽 |           3 勺 |
| 老抽 |           2 勺 |
| 糖色 |      10-15颗冰糖 |
| 蚝油 |           2 勺 |
| 五香粉或十三香 |   炒肉用半勺，卷子用少许 |
| 料酒 |            适量 |
| 葱、姜 |            适量 |
| 蒜 |         适量，切末 |
| 大料 |           2 颗 |
| 香叶 |           2 片 |
| 花椒 |        适量，焯水用 |
| 胡椒粉 |        适量，焯水用 |
| 盐 | 和面用半勺，汤汁调味用适量 |
| 椒盐 |        少许，卷子用 |
| 食用油 |       小半勺，卷子用 |
| 味精 |  不超过 1 勺，分批加入 |
| 花椒油、香油 |   适量，按 1∶1 混合 |
| 水 |            适量 |

## 做法

### 预处理

1. 排骨和五花肉凉水下锅，加入料酒、葱姜、花椒和胡椒粉焯水。第一次煮沸后撇净血沫，保持中小火，使水呈半沸状态。分三次加入凉水，持续撇净浮油和剩余血沫。
2. 捞出后用温水冲洗，排骨沥水。五花肉放入凉水中浸泡 10 分钟，放凉至切片不散后，切薄片并沥水。
3. 根据人数和食量取适量面粉，加入半勺盐，分批加入凉水，和面至面团不粘盆底。在盆底和面团表面撒少许面粉，盖上盖子或保鲜膜保湿，静置 10–30 分钟。
4. 土豆切滚刀块，豆角去筋、切段。

### 烹饪步骤

1. 炒糖色至冒小泡，下入五花肉片。简单翻炒，降低锅温后，下入排骨和大料、香叶、葱姜，继续翻炒至均匀上色。
2. 加入黄豆酱 3 勺、生抽 3 勺、老抽 2 勺、蚝油 2 勺、五香粉或十三香半勺，炒出香味。
3. 加水至高出食材表面 2–3 厘米。后续要焖卷子，水宁多毋少。检查咸度，适量加盐，使汤汁略咸。
4. 转入高压锅，上汽后炖 15 分钟；或用普通锅小火炖 1 小时。
5. 将炖好的肉和汤汁倒入炒锅，下入豆角和土豆，汤汁不够时加水，盖上锅盖，中火炖 10 分钟。同时制作卷子：取出面团擀薄，撒少许椒盐和五香粉或十三香，倒入小半勺食用油并抹匀。折叠面饼，轻轻压实四周后切段。
6. 开盖，分批加入味精，总量不超过 1 勺，避免盖住肉香。保持汤汁微开，将切段后的面片边拉边拧成卷子，平铺在锅面，中间留一个小洞。再盖上锅盖，中火焖 5 分钟。
7. 关火，在预留的洞口放入生蒜末。在勺中按 2∶1 混合花椒油和香油，均匀浇上。

## 补充说明

- 面粉用量按人数和食量调整；未注明具体用量的食材和调料按需添加。
- 炖肉时预留足够汤汁，同时可以比平常炒菜略咸使方便卷子入味。加入豆角、土豆前再次检查，不用完全没过蔬菜，汤汁不足则补水。
- 出锅前确认豆角完全熟透、卷子内部无生面；若未熟，适当延长加热时间。
