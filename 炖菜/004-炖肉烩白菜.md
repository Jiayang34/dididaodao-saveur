# 004 炖肉烩白菜

## 食材

| 食材         |      用量 |
|------------|--------:|
| 猪五花（上五花为宜） |     1kg |
| 红薯粉丝       |      适量 |
| 大白菜        |      适量 |
| 鸡蛋         |      适量 |
| 玫瑰腐乳       | 两块+适量汤汁 |
| 料酒         |      适量 |
| 葱姜蒜        |      适量 |
| 耗油         |      三勺 |
| 老抽         |      三勺 |
| 生抽         |      两勺 |
| 盐、鸡精       |      适量 |
| 桂皮（可选）     |      一根 |
| 小茴香        |      3g |
| 香叶         |      两片 |
| 大料         |      三颗 |
| 白蔻         |      一片 |

## 做法

### 预处理

1. 锅烧烧热后喷少许油，烧猪皮至冒泡。用刀挂掉烤黑的地方后，泡入冷水
2. 切块后焯水，葱姜、料酒、少许胡椒粉、一颗大料。水开打干净浮沫即可，不用多次砸凉水，避免长时间煮制。出锅后热水洗干净、沥干水分
3. 鸡蛋水开后保持沸腾，煮10分钟。泡凉水后剥皮
4. 白菜洗净后，分离菜帮和菜叶，菜帮片成5mm薄片，菜叶切段
5. 红薯粉丝建议提前泡软

### 烹饪步骤

1. 炒糖色至冒大泡和烟，下入五花肉，翻炒使糖色均匀包裹
2. 根据五花肥瘦选择是否煸出油脂，上五花不推荐过度炒制
3. 调小火力，两勺生抽、三勺老抽、三勺耗油，出香味后下入葱姜、小茴香、大料两颗、香叶、桂皮、白蔻，等待再次出香味后加开水
4. 水开后，碾碎两块腐乳并倒入一些腐乳汁，加白开水泄开。再根据个人口味加入足量的盐，需要感觉汤汁比往日吃饭咸两个档次
5. 加入鸡蛋以及最后香料（小茴香，建议使用茶包），转入高压锅500w/中小火，最高压力20-25分钟
6. 葱蒜（没有姜）切末后炝锅，先下入白菜帮，炒软后下入白菜叶。烹入半勺生抽爆香
7. 加入肉汤和开水，建议2：1，也可以根据肉汤咸度调整。咸度比往日吃饭咸一个档次为宜
8. 先下入红薯粉丝变软（不盖锅盖），再下入肉块和鸡蛋（可选），盖锅盖中小火5分钟至粉丝煮熟
9. 出锅前淋小半勺香油（可选）和适量鸡精味精（不宜过多）

## 补充说明

- 焯水时建议放入一颗大料，且焯水和炒制时间不宜过长，因此建议选择新鲜的猪上五花（血沫少且油脂少）
- 盐应适量多放，保证肉内部偏咸，汤汁咸度可在烩白菜时自行调整
- 腐乳建议使用**玫瑰腐乳**，而非大块腐乳，后者咸度较低
- 炒白菜时应使用炝炒，所以下白菜前要保证锅足够热。这一步应注意锅内温度，保证锅温的同时不要炒糊葱蒜末
- 下入粉丝不盖盖子和炝炒都是为了尽可能去除白菜异味
- 鸡精最后放，且不要过多以免抢肉香
