# 003 红汤牛腩

## 食材

| 食材   |   用量 |
|------|-----:|
| 牛骨   | 500g |
| 牛肋条  | 500g |
| 牛腩   | 500g |
| 芹菜段  |   适量 |
| 香菜梗  |   适量 |
| 洋葱丝  |   两颗 |
| 蒜粒   |   两头 |
| 豆瓣酱  |  两大勺 |
| 二锅头  |   两勺 |
| 生抽   |   两勺 |
| 盐、鸡精 |   适量 |
| 香叶   |   两片 |
| 丁香   |   一颗 |
| 大料   |   一颗 |
| 白蔻   |   两片 |

## 做法

### 预处理

1. 牛骨焯水后洗干净，加足够多凉水和姜片，十三香5g，高压锅40分钟
2. 牛腩和牛肋条，焯水并打干净浮沫，切段/块。取焯水后清汤加入牛骨高汤。
3. 起锅加入15-30g油，冷油下入芹菜段、香菜梗、葱段、姜片、1头蒜粒、洋葱丝，煸炒至焦黄后。捞出料渣，加入汤中重复利用。

### 烹饪步骤

1. 在制作好的料油中下入豆瓣酱，翻炒出红油。下入牛肋条和牛腩，加入一头蒜粒和姜片煸炒入味
2. 两勺二锅头和生抽沿锅边淋入，翻炒出酱香味后转移至高汤内
3. 水开后，先根据个人口味加入足量的盐，即可能不要太咸，可比日常炒菜略淡
4. 加入香叶两片、八角一颗、丁香一颗、白寇两片，高压锅上汽后30分钟，出锅后酌情加入鸡精

## 补充说明

- 十三香不要太多
- 盐先放鸡精最后放，都不要过多以免抢肉香
