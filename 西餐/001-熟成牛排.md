# 001 熟成牛排

## 食材

| 食材                    |       用量 |
|-----------------------|---------:|
| 猪熟成牛排（厚度2-3cm）        |       一块 |
| 黄油                    |      一大勺 |
| 蒜                     |  适量，大于5瓣 |
| 迷迭香/百里香               |       一颗 |
| 锡纸                    |   一张用于保温 |
| 黑胡椒（尽量选择可现磨，成品黑胡椒粉次选） | 根据个人偏好适量 |
| 盐                     |         根据个人偏好适量 |

## 做法

### 预处理

1. 牛排擦干水分，两边撒上适量盐和黑胡椒（推荐黑胡椒铺满），静置15分钟
2. 蒜瓣包好后，压裂

### 烹饪步骤

1. 铸铁锅下油，应比平时炒菜稍微多放。最大火（电磁炉2200w）加热两分钟，直至冒烟
2. 牛排擦干水分下锅，保持大火2min，期间轻轻按压过于翘起的地方
3. 牛排翻面，继续大火两分钟
4. 取出放入盘中，并包上锡纸保温
5. 倒出锅内剩余的油后，下入黄油并中小火化开。投入蒜瓣和百里香，煎至蒜瓣变色出焦边，火力保持黄油不冒大烟即可
6. 拨开蒜瓣和百里香，下入控干血水的牛排，以小勺浇淋黄油于牛排表面，待大部分黄油不再留下，出锅

## 补充说明

- 牛排腌制前必须擦干水分，下锅前若因腌制出水也应用厨房纸蘸干
- 盘子可以预先加入防止降温过快
- 本做法为五分熟，每面增加15秒可以提升一分熟度
